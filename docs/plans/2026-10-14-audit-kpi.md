# Continue anyway, audit log and KPI implementation plan

Spec: [audit and KPI](../specs/2026-10-14-audit-kpi-design.md) · Jira: AGT-44 (decision AGT-87;
reference AGT-31, AGT-34). Plugin root: `plugins/quality-code/` (paths below are relative to it unless
they start with `docs/`).

## Global constraints

- No npm dependencies; imports are `node:*` or relative. 2-space indent, single quotes, no semicolons.
- No `AGT`, `FIC`, `warehouse`, `teamsystem` or other project values under `core/`.
- TDD: each task's tests first, then the code.
- The audit log is local and git-ignored. Tests write it only in temporary folders, or turn it off.
- `commands/write.md` and `commands/start.md` are not edited here.
- Commits: conventional subject ending `(AGT-44)`, blank line, `Co-Authored-By` and `Claude-Session`.

## Task A1: the audit module

`core/audit.mjs`: `AUDIT_DIR`, `KINDS` (`gate`, `pipeline`, `jira`, `override`), `auditOff(env, flag)`,
`audit(root, kind, entry, { env, off, now })` (whitelist per kind, `date` added, the folder's own
`.gitignore` written once, never throws), `readJsonl(path)`, `readAudit(root, kind)`.
Tests: `test/audit.test.mjs` (shape per kind, text and paths dropped, unknown kind, off switches,
failed append, self-ignoring folder, tolerant reading).

## Task A2: continue anyway

`core/pipeline/cli.mjs`: `--incomplete-ticket <score>` (whole number below `THRESHOLD`), `--no-audit`;
the outcome gets `incompleteTicket`; `override` logged before the run, `pipeline` after it.
`core/pipeline/card.mjs`: `riskLine({ score, bar }, color)` as the first line after the title.
Tests: `test/pipeline/card.test.mjs` (every verdict, rest of the card unchanged, colour),
`test/pipeline/cli.test.mjs` (outcome, exit unchanged, bad values refused before the run, audit
lines, off switches, failed append).

## Task A3: gate and Jira events

`core/cli.mjs`: `score` logs `gate` (with `missing` keys and the `filled` count); `jira-posted <KEY>
comment|update` logs `jira`; `--no-audit` now turns the log off. `commands/ticket-eval.md` calls
`jira-posted` after a successful comment or push.
Tests: `test/cli.test.mjs`, `test/ticket-eval-command.test.mjs`.

## Task A4: setup

`core/setup.mjs`: `RUNTIME_GITIGNORE` gains `.claude/quality-code/audit/`.
Tests: `test/setup.test.mjs` (the lines, and `git check-ignore` on the audit, boundary and run files).
`test/e2e/sample.test.mjs` sets `QC_NO_AUDIT=1` so the committed sample stays clean.

## Task A5: the rollup

`core/kpi.mjs`: `loadEvents(root)`, `buildKpi(events, { period, project })`, `formatKpiCard(report)`,
`main(argv, env, cwd, { now, stdout, stderr })`; the period from `core/consumption/report.mjs`.
`commands/kpi.md`: run, card, then `1. The AI cost of the same days` / `2. Another period` / `3. Stop`.
Tests: `test/kpi.test.mjs` on synthetic JSONL (the card exactly, the report, periods, empty period,
exit 3 with the places looked, usage errors), `test/kpi-command.test.mjs`.
